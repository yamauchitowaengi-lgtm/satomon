# リバーシ 必殺技カットイン画像プロンプト集（9キャラ）

必殺技を出したときに盤面の上へ表示する横長のカットイン画像を作るためのプロンプトです。画像が無いキャラは、これまでどおり顔絵で表示されます。1枚ずつ置いていけば、置いた分だけ自動で切り替わります。

## 使い方

1. 画像生成ツールに、「参考にする顔絵」を添付します。
2. 下の「共通スタイル」と、キャラごとの「シーン」を続けて貼り付けて生成します。
3. 顔や服装が顔絵と違ってしまったときは、「添付画像と同じキャラクター。顔、髪型、服、色を変えない」を最初に足して作り直します。
4. 気に入った画像を `cutin_<キャラID>.png` の名前で `assets/chars/` に置きます。

## 共通スタイル（全キャラで先頭に付ける）

```
添付した参考画像と同じキャラクターを描いてください。顔、髪型、服装、色は参考画像から変えないでください。
日本のアニメ調のフラットなセル画イラスト。太めの濃い輪郭線、はっきりした塗り分け。
横長16:9、1920×1080。必殺技を発動する瞬間のカットイン用イラストで、キャラクターは画面の中央からやや左に大きく配置し、迫力のある構図にする。
背景は暗めの紺色（#34455a）をベースに、中央から外へ広がる放射状の集中線と、琥珀色（#f2b63a）の光のアクセントを入れる。
文字、ロゴ、透かし、吹き出し、枠線は一切入れない。
```

## キャラ別のシーン

### さとモン「現場モード」（続けて2手打てる）

```
シーン：さとモンが白いヘルメットをかぶり、普段の半目とは違う、鋭くキリッとした目でこちらを見据える。左手は前に突き出して、人差し指と中指の2本を立てる（2手の意味）。右手には測量ノートを持つ。体の後ろに、少しずれた残像のシルエットがもう1体分重なって見える。背景に夕暮れの工事現場のシルエット（ショベルカーとクレーン）。琥珀色の強い光が背後から差す。
```

### はなモン「おねだりアタック」（相手の石を1つ奪う）

```
シーン：はなモンが胸の前で両手を組み、上目づかいで片目をウインクする「おねだり」のポーズ。耳の緑色のお花飾りとパールのネックレスがはっきり見える。画面の右に向かって、ハートと花びらが矢のように飛んでいく。背景は桃色から若草色へのやわらかいグラデーションに、放射状の集中線。

シーン：鈴木さんが片手で眼鏡のブリッジを押し上げ、冷静な視線をこちらに向ける。眼鏡のレンズに、折れ線グラフ、数列、赤い×印が映り込んでいる。周りに半透明のデータウィンドウ（グラフ、数値、×マーカー）が浮かぶ。背景は暗い紺色と、シアンから青の電子的なライン。

```

## うまくいかないとき

- 顔が変わる：先頭の1行（参考画像と同じキャラクター）を強めて、「顔を変えない」と繰り返します。
- 文字が入ってしまう：「文字を一切入れない」を末尾にもう一度足します。
- キャラが小さい：「キャラクターは画面の高さの8割を占める」を足します。
- 横長にならない：「横長16:9、1920×1080」を冒頭に移します。
